# Freecam 替代线框 — 神行聚晶灵魂出窍

## 现象
StructureHighlightRenderer 用 `NoDepthTest` + `POSITION_COLOR_NORMAL` 画结构包围盒线框，但线框从未在游戏中显示。多次排查（RenderType 编译、顶点格式匹配、实体同步、frustum culling）均未定位根因。

## 决策
放弃线框方案，改为纯客户端 Freecam（Camera Mixin）：玩家传送后 WASD 穿墙飞行 60s。

## 方案要点
1. **Camera.setup() mixin 模式**：`@ModifyVariable` at HEAD 设 `gp$freecamOverride` 标志，`@Inject` at RETURN 调用 `setPosition(Vec3)` / `setRotation(float, float)` 覆写摄像机。`@Shadow` 声明 protected 方法。
2. **FreecamHandler 客户端单例**：管理 position/rotation/remainingTicks/velocity，60s 倒计时结束或 Shift 键发 `C2SFreecamEndPacket` 通知服务端。
3. **FreecamInputHandler**：直接读 `mc.options.keyUp/Down/Left/Right/Jump/Sprint`（不用 player.xxa/zza），结束后清零 `player.input` 防止实体移动。
4. **服务端身体保护**：`PlayerTickEvent` 中 `setInvulnerable(true)` + `setNoGravity(true)` + `setPos(bodyX, bodyY, bodyZ)` 锁定位置。
5. **夜视效果**：`player.addEffect(NIGHT_VISION)` 持续 Freecam 全程，帮助观察结构内部。

## 坑
- `Camera.setPosition(Vec3)` / `setRotation(float, float)` 是 `protected` 的。Mixin 中必须用 `@Shadow` 声明，不能强转 `(Camera)(Object)this` 直接调。
- 玩家输入必须在 Freecam 期间清零（`player.input.forwardImpulse = 0`），否则客户端发送移动包导致身体位移抖动。
- 服务端用 `player.setPos()` 每 tick 拉回身体位置防止客户端预测漂移。
