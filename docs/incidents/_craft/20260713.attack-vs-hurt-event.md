## 根因

Forge 事件管道顺序：
```
hurt() → LivingAttackEvent → actuallyHurt()(设 hurtTime/击退/音效) → LivingHurtEvent
```

`LivingHurtEvent` 触发时视觉效果已被 `actuallyHurt()` 写入。

## 修复

使用 `LivingAttackEvent.setCanceled(true)` 取代。该事件在 `hurt()` 入口处触发，取消后整个方法 `return false`，没有任何后续副作用。
