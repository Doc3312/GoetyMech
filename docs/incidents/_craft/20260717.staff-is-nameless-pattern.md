## 症状

巫妖晶匣自动施法时，`VanguardSpell` 召唤数量只有 2~7（随机），而手动持无名法杖固定 7 个。

## 根因

Goety 的很多 Spell 使用硬编码 `staff.is(ModItems.NAMELESS_STAFF.get())` 而非 `rightStaff()` 来判断"最高级法杖"。

| 法术 | 检查方式 | 行为 |
|------|---------|------|
| `VanguardSpell` | `staff.is(NAMELESS_STAFF)` | 7 个 vs 2~7 |
| `SkeletonSpell` | `staff.is(NAMELESS_STAFF)` | 更多数量 |
| `ZombieSpell` | `staff.is(NAMELESS_STAFF)` | 更多数量 |
| `BlackguardSpell` | `staff.is(NAMELESS_STAFF)` | 更多数量 |
| `SoulBoltSpell` | `staff.is(NAMELESS_STAFF)` | 分裂弹 |
| `ThunderboltSpell` | `staff.is(NAMELESS_STAFF)` | 增强效果 |

这 10+ 个地方都用了 `staff.is(ModItems.NAMELESS_STAFF.get())` 而非 `rightStaff()` 或标签系统。

## 修复

- 修复位置：`FleshCasketEvents.tryAutoCast()` — tier 3 + necromancy 走 `NamelessStaff` 分支
- 后续注意：所有 `staff.is(NAMELESS_STAFF)` 的法术都已覆盖，但若 Goety 新增此类法术需对应更新
