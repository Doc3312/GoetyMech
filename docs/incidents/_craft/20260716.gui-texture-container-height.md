## 根因

`GuiGraphics.blit()`有两个关键重载：
- 7参数版：`blit(texture, x, y, u, v, w, h)` — 默认纹理空间256×256
- 9参数版：`blit(texture, x, y, u, v, w, h, texW, texH)` — 显式纹理尺寸

**容器标准高度166px**（84 + 3×18 + 4 + 18 = 166），纹理必须匹配此高度。

## 修复

用户重新设计纹理为标准256×256，容器恢复默认布局（imageHeight=166，背包Y=84，快捷栏Y=142）。

## 经验提炼

1. **容器GUI纹理必须是256×256** — 这是Minecraft容器GUI的标准，7参数blit默认以此为纹理空间
2. **自定义内容放在左上角176×166区域** — 其余区域透明/填充
3. **槽位Y坐标在Container构造函数中配置** — `addSlot()`的第4个参数
4. **imageHeight在Screen.init()中设置** — 必须在`super.init()`之前
5. **inventoryLabelY = imageHeight - 94** — 标准公式，保持标签在背包网格上方
