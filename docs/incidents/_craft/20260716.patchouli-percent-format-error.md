## 症状

Patchouli 条目（`goety:black_book`）文本页若包含 `%` 字符（如 `20%`），会在页面前显示 "Format error: ..." 红字。

2026-07-16 调试应力护盾聚晶条目时发现。

## 根因

Goety 的 `book.json` 中设置了 `"i18n": true`。Patchouli 的 `BookTextRenderer` 在渲染文本页时，会调用 `I18n.get(text)` 进行国际化翻译。

`I18n.get()` 内部调用 `String.format(translated)`。当文本不含翻译 key 时，`Language.getOrDefault()` 返回原文本。`String.format()` 将 `%` 解析为 Java 格式说明符，遇到 `% `（百分号+空格）或 `%c` 等无效格式时抛出 `IllegalFormatException`，被 catch 后返回 `"Format error: " + translated`。

## 修复

用 `%%` 替代 `%` —— 这是 Java `String.format()` 的标准字面百分号转义序列。Goety 自身 Patchouli 条目已大量使用此方式。

## 经验提炼

- Patchouli 条目文本若启用了 `"i18n": true`，`%` 须转义为 `%%`
- 所有 patchouli 条目新增后应 grep 检查有无 `%` 残留
