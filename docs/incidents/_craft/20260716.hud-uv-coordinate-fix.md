# HUD UV 坐标修复：精灵表 x 偏移导致填充条左右空白

date: 2026-07-16
status: verified

## 现象

应力方舟 HUD 的绿色底条左右出现明显空白，未填满棕色背景条内部。

## 根因

`StressArkHUD.java` 中绿色底条的 `blit()` 调用 UV x 坐标为 `0`：

```java
gui.blit(ENGINE_TEXTURE, barX + 9, barY + 2, 0, 21, 117, 5, 128, 90);
```

但 `engine_energy.png` 精灵表中绿色条从 `x=9` 开始（与棕色背景条的边框对齐），导致纹理左侧的透明区域被绘制到了绿色条上，产生左右空白。

## 修复

将 UV x 坐标从 `0` 改为 `9`：

```java
gui.blit(ENGINE_TEXTURE, barX + 9, barY + 2, 9, 21, 117, 5, 128, 90);
```

红色覆盖条同样修正。

## 经验教训

1. 仿照 Goety 精灵表布局时，需要同时复制 UV 坐标偏移量，不能只改 v（y 坐标）
2. Goety 的 `SoulEnergyGui.java` 第 64 行明确使用 `(9, 18)` 作为绿色底条的 UV，说明精灵表中填充内容通常有左边距
3. 精灵表渲染时，UV 的 x=0 不一定是内容的左边界——可能是边框/图标区域
4. 用户说「在编辑软件里绿色和框是严丝合缝的」意味着纹理本身没问题，是 UV 选择错误
5. 先读 Goety 源码确认 UV 约定，再写自己的代码
