# 自定义 RenderType 关闭深度测试

## 现象
StructureHighlightRenderer 用 `RenderType.lines()` 画线框，被方块挡住时不可见。

## 根因
`RenderType.lines()` 启用了默认深度测试（LESS_OR_EQUAL），结构方块在线框前面时线框被剔除。

## 方案
创建自定义 `RenderType`，与 `lines()` 一致但关闭深度测试：
- 用 `RenderType.CompositeState.builder()` 构造
- 关键：`.setDepthTestState(RenderStateShard.NO_DEPTH_TEST)`
- 其他状态复用 `lines()` 的原始值（`RENDERTYPE_LINES_SHADER` + `TRANSLUCENT_TRANSPARENCY`）

## 坑
1. `RenderStateShard` 的字段在 Forge Searge mappings 下是 `protected` —— 不能用，必须通过 **Mixin @Accessor** 暴露。
2. `RenderType.create()` 返回 `CompositeRenderType`（package-private），如果用 `Util.make(() -> { ... })` 会编译报错"类型不可访问"。解决：拆成 `private static RenderType createFoo() { ... }` + `private static final RenderType FOO = createFoo();`。
