# 兵团聚晶/魂灵丰碑架构重构经验

## Goety Focus/Spell 三层架构

```
Layer 1: Focus.use()       — shift = 清 NBT（点按），非 shift = pass 给 wand
Layer 2: DarkWand.use()    — 对 Command/Order/CallFocus 特殊拦截 shift（cannotCast 前）
Layer 3: SpellResult       — isShifting = 差分路（SummonSpell.commonResult 传送仆从）
```

- **Focus.use() 的 shift 只用于物品层 NBT 管理**（解绑），不是施法
- **SummonSpell 的 shift 长按 = 走完整 cannotCast → 扣魂 → SpellResult → 设冷却**
- shift dismiss 要绕过 cannotCast → 只能用 DarkWand 层拦截（CommandFocus 模式）或 SpellResult.isShifting 分流

## SEHelper.decreaseSouls 链路

```
decreaseSouls(player, souls)
  → souls *= soulDiscount(player)    ← 装备折扣（armor slots 的 ISoulDiscount）
  → onSoulEnergyLoss(player, souls)  ← Forge 事件
  → getSEActive(player) ? decreaseSESouls(…) : TotemFinder.FindTotem→decreaseSouls
  → sendSEUpdatePacket（仅 active SE 路径）
```

- **`decreaseSouls` 内部已调 `sendSEUpdatePacket`**（active SE 时），外部不需要重复调
- 非 active SE 且无 Totem → **静默丢弃**，souls 不被扣除
- 创造模式 `!player.isCreative()` 守卫是正确设计

## God Ray 粒子尺寸控制

- `GodRayParticle.render()` 中 `flashDistFromCenter` 和 `flashHeight` **完全硬编码**
- `xSpeed/ySpeed/zSpeed/maxSpeed` 4 个参数全部映射为颜色分量或不使用
- 要缩放 → 只能自定义粒子类型（`ScaledGodRayParticle`，xSpeed→widthScale, ySpeed→heightScale）
- **StretchedGodRayParticle** 是变体但尺寸同样固定

## 跨维度实体创建

- `EntityType.create(level)` 中 level 决定实体归属维度
- `level.addFreshEntity(entity)` 也决定归属
- 丰碑召唤跨维度必须用 `worldIn`（玩家维度）而非 `blockLevel`（丰碑维度）
- `.dat` 文件是世界级路径，用 blockLevel/worldIn 均可
