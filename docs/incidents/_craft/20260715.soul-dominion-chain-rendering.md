# 灵魂统御聚晶锁链渲染迭代教训

## 摘要

锁链渲染花了 3 轮迭代才达到正确效果。根因：不知道纹理图案方向必须匹配 UV 映射方向。

## 失败的尝试

| 尝试 | 问题 |
|------|------|
| uniform 纯红 + entityTranslucent → 红色光柱 | 没图案，像光柱 |
| prisoner_chain 16×16 青灰→红 + UV 不换 → 横锁链 | prisoner_chain 纹样是纵向的（链环沿 Y 轴），而 UV 中 U=长度方向，所以纵向链环被横着铺 → 看着是横的 |
| UV 交换后（V=长度）纹理平铺 → 方向对了但链太细 | 囚徒链只有 3 列像素宽，跨 0.5 格太细 |
| 自作主张重绘椭圆链环纹理 → 被否决 | 用户只要原版风格的纹理，不要自作主张重绘 |

## 正确方案

直接参考 Goety 的 `ObsidianMonolithRenderer`：

- **纹理**：`obsidian_monolith_chain.png` 8×8 横向链环图案（链环沿 X 轴排列），改紫色→红色
- **RenderType**：`entityCutoutNoCull`（非 translucent，链环无需半透明混合）
- **UV**：U（纹理 X，链环横向）= 沿连接线长度平铺，V（纹理 Y，链环纵向截面）= 跨宽度一次过
- **sideOffset**：`scale(0.25)`（0.5 格宽，与方尖碑一致）
- **纹理保留**透明像素作为链环间隙，cutout 自动丢弃

## 教训

1. 纹理图案方向一定要匹配 UV 映射方向：横向图案配 U=长度，纵向图案配 V=长度
2. 先看参考实现再动手：ObsidianMonolithRenderer 已经在 Goety 源码里，花 5 分钟读比 3 轮试错快
3. 不要自作主张重绘纹理：用户要的是"把紫色改成红色"，不是"我重新设计一个链环图案"
4. 方尖碑的链方案是"最佳实践"：entityCutoutNoCull + 紧凑图案 + 原始 UV 映射
5. 链宽 0.5 格（scale 0.25）即可，不需要放大
