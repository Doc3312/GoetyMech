# Freecam 标记泄露：手切旁观者触发神行 HUD

## 症状

手动 `/gamemode spectator` 后，"按R退出神行" HUD 出现，R 键和 F5 被吞噬。

## 根因

`FreecamHUD` 和 `ModClientForgeEvents.onClientTick()` 只检查 `GameType.SPECTATOR`，没有区分"神行触发的旁观"和"手动控制的旁观"。

## 修复

新增 `ModClientEvents.freecamActive` 客户端布尔标记，神行传送时服务端发送 `S2CSetFreecamPacket(true)`，退出时发送 `S2CSetFreecamPacket(false)`。HUD 和按键处理都加上 `freecamActive` 检查。

## 教训

客户端 gameMode 状态是全局的，无法区分来源。任何需要区分"mod 触发的 gameMode 变更"和"用户手动的 gameMode 变更"的场景，都必须通过额外的客户端标记来控制。
