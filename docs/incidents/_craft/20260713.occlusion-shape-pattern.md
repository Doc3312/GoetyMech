# getOcclusionShape 默认行为导致相邻方块面剔除

status: verified

## 症状

DirectionalKineticBlock 使用非完整 JSON block model（如远程引擎 `remote_engine.json`），放置后背后方块的连接面材质丢失（被剔除）。

## 根因

`BlockBehaviour.getOcclusionShape()` 默认调用 `getShape()`。当 `getShape` 返回非空（如 `AllShapes.CASING_12PX` = `[0,0,0]→[16,12,16]`），该范围覆盖区域内相邻方块的接触面会被 Culling 引擎剔除，但模型在该区域可能有镂空/延伸超出遮挡范围，导致视觉不同步。

## 修复模式

```java
@Override
public VoxelShape getOcclusionShape(BlockState state, BlockGetter level, BlockPos pos) {
    return Shapes.empty();
}
```

Create 同类处理参考（20260713 发现时）：

| 方块 | getOcclusionShape |
|------|-------------------|
| MetalLadderBlock | `SIX_VOXEL_POLE` (6x6x16 柱) |
| TableClothBlock | `TABLE_CLOTH_OCCLUSION` (16x1x16 平板) |
| FluidPipeBlock | `box(4,4,4,12,12,12)` (4x4 中心块) |

## 适用范围

任何使用自定义 JSON block model 且模型未填满完整 16x16x16 方块的 Create kinetic block（含 DirectionalKineticBlock / RotatedPillarKineticBlock 体系），都可能出现同类问题。
