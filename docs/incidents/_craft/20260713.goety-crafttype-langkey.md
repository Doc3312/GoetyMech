## Goety 自定义 craftType 的 lang key 要求

### 现象

为 Goety 新增自定义流派（craftType `"mechanical"`）后，JEI 和 Patchouli 的"仪式类型"标签显示为空白或回退到默认值，因为缺少 `jei.goety.craftType.mechanical` 语言键。

### 根因

`IRitualType.getName()` 返回的字符串（如 `"mechanical"`）仅作为内部注册键。Goety 的 JEI/Patchouli 集成使用以下模式渲染类型标签：

```
I18n.get("jei.goety.craftType") + I18n.get("jei.goety.craftType." + craftType)
```

因此必须为每个新 `craftType` 添加对应的：
- `jei.goety.craftType.<name>` → 英文（en_us）和中文（zh_cn）

### 额外发现

**`craftType` 不会出现在聚晶物品的显示名称或 tooltip 上。** 聚晶显示的是 `SpellType`（法术类型枚举）。`craftType` 仅影响：
1. JEI 分类标题和配方面板
2. Patchouli 手册条目（通过 `RitualRecipeProcessor`）
3. 仪式结构验证（`RitualRequirements.getStructures()`）
4. 完成效果触发（`Ritual.onFinishRitual()` 调用 `IRitualType.onFinishRitual()`）

### 教训

新增 craftType 时，lang 文件中的 `jei.goety.craftType.<name>` 必须与 Java 注册同步添加，否则 JEI/Patchouli 显示异常。
