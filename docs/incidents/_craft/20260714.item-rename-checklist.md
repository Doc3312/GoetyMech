# Item Rename Checklist — 物品重命名必须扫描的全域引用

**日期**：2026-07-14  
**场景**：`time_focus_pouch` → `neuro_stasis_focus_pouch`

## 根因

重命名一个注册物品时只改了注册类和 lang，漏掉了 `ModCreativeTab.java`，导致 compile error。

## 必须扫描的引用清单

| # | 位置 | 检查项 | 本案例 |
|---|------|--------|--------|
| 1 | 注册类 | `ModItems.java` 字段名 + 注册名字符串 | `TIME_FOCUS_POUCH` + `"time_focus_pouch"` |
| 2 | 物品 Java 类 | 类名 + 内部 translation key | `TimeFocusPouch` → `NeuroStasisFocusPouch` |
| 3 | 翻译文件 | `zh_cn.json` + `en_us.json` key | `item.goetymech.time_focus_pouch` |
| 4 | 模型 JSON | `models/item/` 文件名 + `layer0` 路径 | `time_focus_pouch.json` + `item/time_focus_pouch` |
| 5 | 纹理 PNG | `textures/item/` 文件名 | `time_focus_pouch.png` |
| 6 | 配方 JSON | `recipes/` 文件名 + `result.item` | `time_focus_pouch.json` + `goetymech:time_focus_pouch` |
| 7 | Curios 标签 | `data/curios/tags/items/*.json` | `belt.json` |
| 8 | CreativeTab | `ModCreativeTab.java` | **本次漏掉** → compile error |
| 9 | 客户端事件 | `instanceof` 检查 + 方法名 | `ModClientForgeEvents.java` |
| 10 | 设计文档 | `docs/design/` 文件名 + 内容 | `time-focus-pouch-architecture.md` |
| 11 | 物品文档 | `docs/items/` 目录名 + 内容 | `curio/time-focus-pouch.md` |

## 工作流改进建议

在 `AGENTS.md` 或脚本中固化一条规则：**任何注册名重命名操作前，先全局 grep 旧注册名 + 旧类名两个 pattern**。本次若提前执行 `grep -r "time_focus_pouch\|TimeFocusPouch" src/` 可避免遗漏。
