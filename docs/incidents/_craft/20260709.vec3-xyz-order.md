## 症状

`handleMonumentSummon` 日志显示 `spawned 4/4`（`addFreshEntity` 返回 true），但玩家视野内无任何仆从，FLASH 粒子也看不见。跨维度检查确认在同一维度。

## 根因

`getMonumentSpawnPos` 中：

```java
return new Vec3(x, z, player.getY());  // ❌ Vec3(x, y, z) 写成 (x, z, y)
```

Vec3 构造器签名为 `(double x, double y, double z)`，但参数传了 `(x, z, player.getY())`，导致 Y 取了 z 坐标值（~-327），Z 取了 player.getY()（-60）。mob 生成在 Y=-327 的基岩深处，即刻窒息消失。

## 经验提炼

- `addFreshEntity` 成功 ≠ 实体会出现在玩家视野（可能在墙内/地下/异维度）
- Mob 在 Y<0 的深处被释放后会因窒息快速死亡，但死亡过程可能快到玩家看不到
- 定位手法：在生成位置喷 FLASH 粒子 + 日志同时打印坐标和维度，FLASH 粒子不生成说明位置在玩家不可见区域
- Vec3/Vec3i 的 x/y/z 参数顺序要格外留意，这是 Java 的构造器无法用命名参数约束的经典问题
