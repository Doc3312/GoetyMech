# 配方开发：pure_unholy_blood 不是独立注册 ID

status: verified
date: 2026-07-13
slug: recipe-pure-unholy-blood
domain: _craft

## 问题

T3 点将台配方 JSON 中使用 `goety:pure_unholy_blood` → 配方解析失败：
```
Unknown item 'goety:pure_unholy_blood'
```

## 根因

Goety 只注册了一个 `goety:unholy_blood`（`UnholyBloodItem`）。"至纯之血" 是同一物品的 NBT 属性（`pure=true`），通过 `isPure()` 判断后切换 `getDescriptionId()` 显示名。**配方 JSON 无法使用 NBT 属性物品**。

## 修复

`goety:pure_unholy_blood` → `goety:unholy_blood`

## 教训

1. 翻译 key ≠ register ID。`item.goety.pure_unholy_blood` 是翻译 key，不是物品注册名
2. 任何从 lang 文件推断出的物品名都必须回查 `ModItems.java` / `ModBlocks.java` 确认确切注册名
3. Goety 多处用单物品+NBT 实现多形态（`UnholyBloodItem`、`OminousBloodItem`等），配方只能用注册名
