# LeftClickBlock 事件多次触发 + 防连点设计

## 现象

`PlayerInteractEvent.LeftClickBlock` 在 Forge 中对单次物理点击可能触发多次，且可能跨不同 tick（如 tick 100 和 tick 101 各一次）。

## 教训

1. **同 tick 去重不够**：`gameTime == lastClearClickTime` 能过滤同一 tick 的重复，但跨 tick 的重复（间隔 1tick）同样会触发防连点
2. **防连点提示本身会干扰 UX**：跨 tick 重复触发时显示 "操作过快" 会覆盖前一次的正确提示——用户只点了一下却看到防连点，体验差
3. **解决方案**：防连点措施保留（防止 20t 内重复处理），但 `-1` 结果静默 return，不输出任何提示

## 推荐模式

```java
public int handleClearClick(long gameTime) {
    if (超时) reset;
    if (同tick重复) return 当前进度;
    if (短间隔) return -1;  // 静默忽略
    处理 → 更新状态;
}
```
