# 存档加载后绑定关系丢失问题

**状态**: verified

**日期**: 2026-07-08

**问题描述**:
重进存档后约1秒内显示正常，但很快变成0/0。Reader和Engine数据正确，但绑定关系消失，破坏Engine时Reader网络不更新。

**根因分析**:
1. `onReaderLoad()` 在Reader加载时用初始值（0）填充缓存，覆盖了真实数据
2. `tick()` 的 `loadTickDelay` 机制在延迟结束后只填充缓存，没有触发 `distributeBudget()` 恢复绑定

**修复方案**:
1. 移除 `onReaderLoad()` 中的缓存填充逻辑
2. 在 `tick()` 的 `loadTickDelay == 0` 时，除了填充缓存外，还需将所有有引擎绑定的Reader标记为dirty，触发 `distributeBudget()`

**涉及文件**:
- `GlobalStressLinkManager.java` — 添加延迟初始化机制
- `StressLinkEvents.java` — 添加PlayerLoggedInEvent监听

**教训**:
- 存档加载时，区块和网络数据可能延迟初始化，需要等待足够时间
- 缓存填充和绑定恢复必须同步进行
- 需要在多个入口点（加载、登录）确保状态一致性
