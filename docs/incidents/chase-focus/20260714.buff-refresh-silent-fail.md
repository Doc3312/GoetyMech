## 症状

每次 Shift 闪现时，`C2SVoidBlinkPacket` 试图刷新 VoidMark 的持续时间，但实际上 buff 倒计时没有任何变化。

## 根因

```java
// C2SVoidBlinkPacket.java (原代码)
windowSec = effect.getDuration() / 20;  // int 除法截断
int refreshedTicks = windowSec * 20;    // 回转后 ≤ 原值
player.addEffect(new MobEffectInstance(..., refreshedTicks, ...));
```

`LivingEntity.addEffect()` 内部调用 `MobEffectInstance.update()`：
- 新 duration **必须严格大于** 现有 duration 才会更新
- 相等或更小 → `update()` 返回 false → 静默忽略

整数除法截断导致 `refreshedTicks ≤ effect.getDuration()`，每次刷新都失败。

## 修复

1. `VoidMarkEffect` 新增 `TAG_WINDOW_DURATION` 常量
2. `VoidBlinkSpell.SpellResult` 将 `effectDuration` 存入 PersistentData
3. `C2SVoidBlinkPacket` 改为从 `TAG_WINDOW_DURATION` 读取满时长 → 直接 `addEffect` 覆盖
4. 所有 cleanup 点同步移除新 tag

## 经验提炼

刷新 MobEffect 时，不要读取当前剩余时长做数学运算（容易产生 ≤ 原值的陷阱）。应保存初始满时长并直接使用。MC 的 `addEffect` 对新时长的要求是**严格大于**现有值。
