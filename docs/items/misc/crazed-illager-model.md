# Crazed Illager Model

CrazedIllager 实体模型定义（HierarchicalModel）。

锯片（saw_blade）设计：
- **平面**：YZ 平面（薄片在 X 方向，`(-0.5, -4, -4, 1, 8, 8)`）
- **牙齿**：8 齿环状排列在 YZ 平面，半径 4.5
- **自旋**：绕 X 轴旋转（`xRot = ageInTicks * 0.5F`）
- **效果**：正面面对玩家时仅见一条细边（不可见），侧面可见完整圆盘旋转
