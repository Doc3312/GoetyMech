# C2S Void Blink Packet

客户端→服务端虚空闪现传送请求包（无 payload）。服务端处理：
1. 检查玩家是否有 VoidMark 效果
2. 从 PersistentData 读目标 UUID、剩余次数
3. 计算目标身后位置，安全检测（方块碰撞/岩浆）
4. 不安全 → 传送至目标坐标
5. 剩余次数 -1，重置窗口倒计时
6. 剩余次数归零 → 清理效果

- **2026-07-02** — 重构为锁定+闪现逻辑。新增安全检测（noCollision + 岩浆检查），无 payload 设计。
