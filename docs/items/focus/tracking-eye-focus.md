# 追猎聚晶 — goetypunk

## 身份

- 类型：focus
- 注册类：ModItems.TRACKING_EYE_FOCUS
- Java 类：TrackingEyeFocus (extends MagicFocus)
- 注册 ID：`goetypunk:tracking_eye_focus`
- 前身：`void_blink_focus`（虚空闪现聚晶）
- 底层法术：VoidBlinkSpell（锁定+多次闪现传送）

## 设计意图

远程战斗聚晶：锁定目标后施加虚空印记，玩家可在窗口期内多次按 Shift 闪现到目标背后。原名"虚空闪现聚晶"，现更名为"追猎聚晶"以匹配新主题。
